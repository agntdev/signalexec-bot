# SignalExec Bot

Telegram bot that monitors one channel for trade signals, posts parsed signal cards to the owner's private chat, and enables one-tap semi-automatic execution on IQ Option with confirmation.

Spec: [`docs/blueprint.md`](docs/blueprint.md).

Built on [agnt-gm.ai](https://agnt-gm.ai). The whole bot is built and refined here as pull requests across successive build passes.
